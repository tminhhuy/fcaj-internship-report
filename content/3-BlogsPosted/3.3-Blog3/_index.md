# Top 16 AWS services every engineer should know

Understanding AWS is not about memorizing service names, but about knowing each service's role in your system architecture.

### Compute

* **Lambda:** runs event-driven functions with automatic scaling.
* **ECS:** orchestrates containers with AWS-native tooling.
* **EKS:** provides a managed Kubernetes control plane.

### Data

* **RDS:** managed relational databases.
* **DynamoDB:** serverless key-value and document storage.
* **ElastiCache:** managed in-memory caching for low-latency access.

### Application integration

* **SQS:** durable queues for asynchronous work.
* **SNS:** pub/sub messaging and notification fan-out.
* **EventBridge:** routes events between applications and services.
* **Step Functions:** orchestrates workflows with retries, waits and branching.

### Networking & delivery

* **API Gateway:** manages APIs with authentication and throttling.
* **CloudFront:** caches content closer to users.
* **VPC:** isolated virtual networks for cloud resources.

### Security & operations

* **IAM:** manages access through policies and roles.
* **CloudWatch:** collects metrics, logs and operational data.
* **Secrets Manager:** stores and rotates application credentials.

### AI integration

Scalable infrastructure is only part of the challenge. When adding AI to products, companies also need to connect models to existing data, manage AI workloads and keep production secure and reliable.

AWS supports this with **Amazon Bedrock** for building generative AI applications and **Amazon Bedrock AgentCore** for deploying and operating AI agents at scale, helping teams move from prototype to production and scale AI features across many customers.
