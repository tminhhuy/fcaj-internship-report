This section collects the technical articles I wrote during the internship.

### [Blog 1 - Trusted ledger architecture on AWS: from QLDB to tokenomics with Amazon Managed Blockchain](3.1-blog1/)
How Amazon QLDB and Amazon Managed Blockchain can be combined to build a verifiable ledger, then extended to stablecoins (Hyperledger Fabric) and NFTs (Ethereum). Covers three use cases and an event-driven architecture with API Gateway, Lambda, Kinesis, Aurora, ElastiCache and Step Functions.

### [Blog 2 - What is AWS VPC?](3.2-blog2/)
An introduction to the core building blocks of Amazon VPC: public/private subnets, Internet Gateway, NAT Gateway, route tables and VPC Peering, with an example and quick facts.

### [Blog 3 - Top 16 AWS services every engineer should know](3.3-blog3/)
16 key AWS services grouped by their role in a system architecture: compute, data, application integration, networking and security/operations, plus AI integration with Amazon Bedrock.
