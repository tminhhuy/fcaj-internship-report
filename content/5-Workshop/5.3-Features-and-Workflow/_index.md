SCA covers the four core capabilities of the assignment (**OCR Scan**, **Smart Summary**, **Scoreboard**, **Cite/Source Link**) and adds features that let users check the results themselves.

Every uploaded contract creates exactly one AWS Step Functions execution and passes through the 8 steps users see on the web. Only S3 keys and counters are passed between steps, so contract text and personal data never appear in the execution history.
