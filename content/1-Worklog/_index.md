This worklog records my **12-week** internship in the **First Cloud AI Journey** program, from **07/09/2026** to **27/11/2026**.

The roadmap has three phases:

* **Weeks 1–7: AWS foundations.** Account and cost, VPC networking, EC2 and Auto Scaling, S3 and CloudFront, security, databases, monitoring; ending with a mid-term review and exam.
* **Weeks 8–10: Modern architectures.** Serverless and event-driven design, Infrastructure as Code and CI/CD, containers and data analytics, while kicking off the team project.
* **Weeks 11–12: Project.** Apply Well-Architected, then design and build an **AI agent that reviews and summarizes B2B/B2C contracts** with Amazon Textract, Amazon Bedrock and AWS Lambda.

Each week includes objectives, a hands-on architecture diagram, a daily task table with references, key knowledge, hands-on results, representative commands, challenges and solutions, and next week's plan.
